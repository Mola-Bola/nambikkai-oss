# The one model Nambikkai will run, pinned.
#
# ADR 003: the model is NEVER fetched at runtime. ops/fetch-model.sh reads this
# file, downloads exactly these files at exactly this revision, and refuses to
# install anything whose sha256 does not match. Nothing else may write to
# models/, and no code path in app/ downloads anything at all.
#
# all-MiniLM-L6-v2 is Apache-2.0, published for reuse, and runs here through
# ONNX Runtime: no torch, no server, no network at inference. It clears the
# ethics gate (licensed and explicitly published) and nothing a user writes
# ever goes into it or back to it.
#
# WHY THIS ONE. Smaller static models were tried first and measured against
# tests/fixtures/relevance.json. potion-base-8M could not separate related
# entries from unrelated ones at any threshold (gap -0.052); potion-retrieval
# -32M barely could (+0.012); this model separates them by +0.135 at about 3ms
# an entry. See the header of app/backend/embed.py for the full comparison.
#
# To change models: edit this file, run `make model`, then `make index` to
# rebuild the vectors, then re-derive the floors in app/backend/index.py from
# the fixtures. Vectors from two different models are not comparable.
