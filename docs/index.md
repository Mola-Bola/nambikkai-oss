# Nambikkai

**Trust, with receipts.**

Your agents remember your life. Nambikkai is how you trust them with it.

Personal agent systems — PAI, LifeOS, and every folder-of-markdown OS like them — give
an AI durable memory of your money, health, family, and plans, plus tools to act. That
combination (private data + tool access + untrusted content) is the
[lethal trifecta](https://simonwillison.net/2025/Jun/16/the-lethal-trifecta/), and in
most systems the only thing standing between your national ID and an outbound MCP call
is a sentence in a prompt.

Prompts are hopes. Nambikkai is mechanism — four of them:

<div class="grid cards" markdown>

- **Receipts** — every durable fact carries `[src | date | tier | ttl]`: where it came
  from, when it was confirmed, how much to trust it, when to re-check.
  [→ Concepts / Receipts](concepts/receipts.md)

- **The Perimeter** — identifier-shaped bytes are blocked at the harness boundary
  (file writes, shell args, MCP payloads) with an exit code, not a suggestion.
  [→ Concepts / The Perimeter](concepts/perimeter.md)

- **Drills** — every incident becomes a synthetic corpus case the day it's resolved,
  and replays on every test run, forever.
  [→ Concepts / Drills](concepts/drills.md)

- **The Gate** — unattended agents are mechanically unable to commit; they stage, you
  approve. [→ Concepts / The Gate](concepts/gate.md)

</div>

## Not an OS. A component.

Nambikkai is deliberately one cog in your system of systems. Everyone is building
airports — ticketing, baggage, control towers. We built the security checkpoint, once,
composable into any of them. Install it into the agent system you already run and keep
everything else.
